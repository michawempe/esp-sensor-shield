# Firmware

The Arduino sketch reads the sensors and sends their latest values over USB
Serial every 20 ms. Use [PlatformIO](../platformio/README.md) to build and upload.

## Configuration

Send one JSON object followed by a newline. Each key is a shield port:

```json
{"B1":{"type":"slider","name":"slider1","smoothingMs":100},"A1":{"type":"button"}}
```

This replaces the whole configuration. The reply is
`{"status":"config_applied","persisted":true}` when saving succeeds.
Settings are stored on the ESP and restored on boot. Send `{}` to remove all
configured sensors. Missing names are generated by type, such as `slider1`.

| Ports | Types | Parameters and defaults |
|---|---|---|
| A | `button`, `switch` | No parameters; 0 is active |
| B | `slider`, `light`, `magnet` | `inMin: 0`, `inMax: 4095`, `outMin: 0`, `outMax: 1` |
| B | `sound` | `inMin: 100`, `inMax: 4095`, `outMin: 0`, `outMax: 1` |
| C | `joystick` | `midCutoff: 100`, `edgeCutoff: 0`, `outMin: -1`, `outMax: 1` |
| C | `encoder` | `fullRotation: 360`, `modulo: false` |
| C | `distance` | `inMin: 30`, `inMax: 600` (mm), `outMin: 0`, `outMax: 1` |
| D | `touch` | `threshold: 50000`; 1 is active |

At most two distance sensors can run at once. Joystick cutoffs set the center
and edge dead zones. Encoder `modulo` wraps the output at `fullRotation`.

Slider, light, magnet, sound, joystick and distance accept `smoothingMs` from
0 to 10000. Zero disables smoothing; try 100 for a steadier response. Higher
values respond more slowly. Smoothing affects `value`, not `raw`; distance also
uses a median filter.

## Output

```json
{"data":{"slider1":{"type":"slider","port":"B1","raw":2048,"value":0.5,"inMin":0,"inMax":4095,"outMin":0,"outMax":1,"smoothingMs":100}}}
```

`value` is the mapped output. Joystick readings have `{ "x": ..., "y": ... }`
for both `raw` and `value`. Light inverts the ADC reading; sound reports the
peak-to-peak level; distance reports filtered millimetres.

Unavailable readings are `null`, with an `error` field where provided. Config
changes and USB backpressure can briefly interrupt output. An unfinished input
line times out after one second; send a newline before retrying the command.

## Timing and code changes

ADC1 uses DMA: nominally 16 kHz per channel with sound, or 1 kHz without it.
Above five channels, the sound sample rate drops to keep the total at or below
80 kHz. Sound windows remain 20 ms. Distance uses a 20 ms measurement budget
and expires after 100 ms without a result.

Add sensor classes in `sensors/` and register them in `config/ConfigManager.h`.
Use `analogSampler` for ADC1 pins; do not mix it with `analogRead()` on ADC1.
ADC2 uses direct reads. Config changes stop DMA before replacing sensors and
restart it after saving to flash. Pin assignments are in
[PortMap.h](ilab_ESP32_S3_Sensor_Shield/PortMap.h).

For Arduino IDE, open the `.ino` in `ilab_ESP32_S3_Sensor_Shield/`. Use core
3.3.7, ArduinoJson 7.4.2 and Pololu VL53L0X 1.3.1. Select ESP32S3 Dev Module,
USB-OTG (TinyUSB), CDC on boot, 8 MB QIO flash at 80 MHz, 8 MB SPIFFS partitions,
PSRAM disabled and 115200 baud for upload and monitor.
